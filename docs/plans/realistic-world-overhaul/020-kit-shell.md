# Plan 020: Building kit shell: manifest schema, walls with openings, floors and stairs, roofs and colliders

Epic E2. Estimated turns: 60. Model: opus.

## Goal

Build the generator that turns a building manifest into a walkable building shell: validated schema, wall segments with door and window openings, floor slabs with stairwell holes, stairs (meshes and collision), ceilings, five roof types, perimeter walls split from interior partitions, merged meshes (draw-call budget) and colliders. Everything runs headless so `check:buildings` can build and walk a building in Node. This plan covers geometry and collision only; room content, door leaves, lights, lifts and props come in plan 021 (plan 021 only places things: the stair meshes and stair colliders are built HERE).

Conventions used by every step (ARCHITECTURE.md 10.8): building-local coordinates have the origin at the footprint centre; compass N = -z, S = +z, E = +x, W = -x; the front of a building faces +z. `bounds` is `[x0, z0, x1, z1]` with x0 < x1 and z0 < z1. A room wall letter names the room edge: N is the edge z = z0, S is z = z1, W is x = x0, E is x = x1. The shell is built in building-local coordinates with axis-aligned geometry only; the world placement `{ x, z, rot, y }` is applied by the caller (plan 021 sets `root.position` and `root.rotation.y`) and by `addShellColliders` for colliders. Placement transform of a local point (lx, lz): world `(x + lx*cos(rot) + lz*sin(rot), z - lx*sin(rot) + lz*cos(rot))`; the inverse is `lx = (X-x)*cos(rot) - (Z-z)*sin(rot)`, `lz = (X-x)*sin(rot) + (Z-z)*cos(rot)`. A stair `dir` letter maps to the climb angle `d` with climb vector `(sin d, cos d)`: S 0, E PI/2, N PI, W -PI/2; the world angle is `d + rot`.

Fixed numbers: perimeter wall thickness 0.30 (flush inside the footprint), partition thickness 0.15, floor slab thickness 0.20 (its top is at the floor `y`), rooftop parapet 1.0 m (every wall on a `rooftop: true` floor is 1.0 m high), decorative flat-roof parapet 0.9 m, step rise about 0.2 m, rail height 0.9 m and thickness 0.05, tiny wall pieces under 0.05 m are dropped, tolerance for "on the same line" is 0.05 m.

### Step 2: Wall plan: segments, openings and the opening record

- Derivation, per floor. Collect the four edges of every room on that floor as segments `{ axis, c, a, b, room }` (`axis` "x" for N and S edges that run along x at z = `c`, "z" for W and E edges that run along z at x = `c`). An elementary interval lies on the PERIMETER when `c` equals the matching footprint edge within 0.05 (N: -d/2, S: d/2, W: -w/2, E: w/2), otherwise it is INTERIOR (a shared edge, or an edge of a room that touches nothing, so a room is always enclosed). Drop segments shorter than 0.05 m. Wall box of a segment `[a, b]`: perimeter walls are 0.30 thick, flush inside the footprint (north edge: `cz = -d/2 + 0.15`, `hz = 0.15`; south `d/2 - 0.15`; west `cx = -w/2 + 0.15`; east `w/2 - 0.15`) and run the full `[a, b]` (overlap at the corners is accepted); interior walls are 0.15 thick centred on `c`. `yMin` is the floor `y` and `yMax` is `floor.y + floor.height`, except on a `rooftop` floor where every box has `yMax = floor.y + 1.0`.

### Step 4: Shell meshes: walls, floors, ceilings, stairs and roofs, merged by material

Deliver:
- `tests/unit/kit/shell.test.js` first. `src/world/kit/shell.js` exports `buildShell(manifest, ctx)` where `ctx = { getMaterial }` only (`getMaterial(name, { tint })` of `src/engine/materials.js`; other keys are ignored; Three.js is imported directly, the module touches no `window`, `document` or WebGL), returning `{ exterior, interior, stats }`: two `THREE.Group` named `exterior` and `interior`, both in building-local coordinates, every mesh and both groups with `userData.layer` `"exterior"` or `"interior"`, and `stats = { meshes: { exterior: n, interior: n }, triangles, wallBoxes, openings }` (`triangles` counts both groups, `wallBoxes` and `openings` are the lengths of the wall plan arrays). - Method: every box is built as SIX independent quads by a helper `boxFaces(cx, cy, cz, sx, sy, sz)` returning `[{ face: "+x" | "-x" | "+y" | "-y" | "+z" | "-z", geometry }]` (positions and normals in place, axis aligned, no rotation), the `-y` face is always skipped for walls, so each face can be sent to its own group and material.
