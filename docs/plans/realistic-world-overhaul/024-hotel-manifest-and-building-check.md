# Plan 024: check:buildings and the Grand Hotel structure manifest

Epic E2. Estimated turns: 60.

## Goal

Create the machine check that enforces the Rich detail bar (`npm run check:buildings`) and the structure of the first real building, the Grand Hotel (zone id `plaza`): footprint, three levels (ground, first floor, roof terrace), all 14 spaces, doors, 24 windows, two stairs, one lift, exterior detail counts. Objects and lights are added by plans 026 and 027; the check has stages, and every manifest DECLARES the stage it has reached (`"stage": "structure|rooms|full"`), so the gates runner (`scripts/check-buildings.mjs` with no flags, run by `gates:full`) checks each building only at the stage it declared and never fails on a half-built hotel. Plan 024 declares `plaza` at `structure`, plan 026 raises it to `rooms`, plan 027 to `full`.

Headless context: plan 021 exports `createHeadlessContext()` (`src/world/kit/headlessContext.js`); this plan uses it for every headless build in `scripts/check-buildings.mjs` and in its tests and does not write another stub context. Conventions of plan 021 hold (room-relative `y`, interior door `wall` letter = the `from` room wall, `at` = offset along the wall from the wall centre, positive toward +x on N/S walls and +z on E/W walls; for exterior doors and all windows the wall is the footprint wall).
