# Plan 028: Textured terrain: heightfield module and a four-layer splat material

Epic E2. Estimated turns: 60.

## Goal

Replace the v1 vertex-colour terrain with a textured one: a pure heightfield module (`createHeightField`, flat areas, paths, an island edge that is always under water), splat weights (grass, sand, dirt road, rock) and ONE terrain mesh whose standard material is extended with the four CC0 texture sets of plan 013 (`grass`, `sand`, `dirtRoad`, `rockCliff`). The island stays at the v1 size (v1 `WORLD_RADIUS` 180, `TERRAIN_SIZE` 420) and every v1 zone keeps its height; plan 033 later swaps the data (radius 300, town plan) through the same API.

Decisions fixed here: (1) the v1 terrain code is MOVED into `src/world/terrain/height.js` unchanged where it is not listed as changed below, and the v1 heights at 28 points are captured into a fixture BEFORE the move, so the move cannot silently change the world; (2) `buildTerrain()` in `src/world/terrain.js` keeps its name and keeps `mesh.userData.sampleHeight` (read by the camera, buildings and props, and by the collision world through plan 016) and sets it to the new `heightAt`; (3) the terrain segment count per tier lives in ONE pure function `terrainSegments(tier)` in `terrainMesh.js` (not in `TIER_SETTINGS`, whose test is frozen); plan 033 changes the numbers there and nowhere else; (4) texture maps come from the plan 013 registry through `getMaterial(name)` (a material is only used as the holder of `map` and `normalMap`, read every frame, so late loads and tier swaps of plan 013 just work); (5) terrain UVs are not used: the shader tiles by world x and z divided by a tile size in metres.

There is no `shoreDistance`. The numbers 180 and -1.2 are plain defaults: callers pass `WORLD_RADIUS` and `WATER_LEVEL`.
- Exact order of operations of `heightAt(x, z)`. (a) `d = hypot(x, z)`, `nd = d / radius`, base = the v1 islandShape: `nd < 0.65` gives `2.2 + cos(nd * PI * 0.5) * 0.8`, `nd < 0.95` gives `1.2 * (1 - (nd - 0.65) / 0.3)`, otherwise `-2.5 * (nd - 0.95) / 0.2`. (b) `h = base + noise1(x * 0.06, z * 0.06) * 0.9 + noise2(x * 0.18, z * 0.18) * 0.35` with `noise1 = smoothNoise2D(9271 + seed)` and `noise2 = smoothNoise2D(1984 + seed)` (seed 0 is the v1 world; the URL `?seed` is NOT passed here). (c) Island edge, NEW because v1 plus noise stays above the water level at the radius (about -0.6 plus noise of up to 1.25): `t = smoothstep(0.8 * radius, radius, d)`, `h = h * (1 - t) + (-3.0) * t`, and for `d > radius` `h = -3.0 - 0.02 * (d - radius)`. So for `d <= 0.8 * radius` the value is exactly v1, and for `d >= 0.95 * radius` it is below -2.3 whatever the noise. (d) Flat areas, in list order, each blends the CURRENT h toward its `y`: a circle `{ x, z, r, y }` has `t = dist / r` and, when `t < 1`, `w = 1 - t * t`; a rect `{ kind: "rect", x, z, hx, hz, blend, y }` (axis aligned) has `dOut = hypot(max(abs(x - cx) - hx, 0), max(abs(z - cz) - hz, 0))` and, when `dOut < blend`, `w = 1 - (dOut / blend) ^ 2`; then `h = h * (1 - w) + y * w`. The plateau height is therefore reached only at the centre of a circle and everywhere inside a rect. Overlapping areas compose; this differs from v1 first-match only inside the v1 `notice` zone (it overlaps `plaza`), and the reference test below skips that one centre. (e) Paths: for each path the distance `dist` to its polyline (segment distance), influence `max(0, 1 - dist / halfWidth)`, `pInf` = the maximum over paths, `h = h * (1 - pInf * pathBlend) + pathLevel * pInf * pathBlend`. (f) Clamp to [-12, 40]. `slopeAt(x, z)` = `hypot(dh/dx, dh/dz)` by central differences with step 0.5 m (`(h(x + 0.5) - h(x - 0.5)) / 1.0`). `isWater(x, z)` = `heightAt(x, z) < waterLevel`.
- `src/world/terrain/splat.js` (pure): `createPathMask(paths, { falloff = 1.5 } = {})` returns `pathMask(x, z)` = `1 - smoothstep(w, w + falloff, dist)` for the nearest path (the maximum over paths), with `w = path.dirtHalfWidth ?? path.halfWidth`; `splatWeights({ h, slope, pathMask })` returns `[grass, sand, dirt, rock]` computed exactly as: `sand = 1 - smoothstep(0.6, 1.8, h)`; `dirt = pathMask * (1 - sand)`; `rock = smoothstep(0.55, 0.85, slope) * (1 - sand) * (1 - pathMask)`; `grass = max(0, 1 - sand - dirt - rock)`. The four sum to 1 (1e-9) and lie in [0, 1]. So sand wins at the water level, dirt beats rock and grass on a path, rock reaches half weight at slope 0.7, grass is the rest.
- Tests (write them to fail first). height.test.js: determinism (two fields equal at 50 seeded points, `seed: 1` differs somewhere); the v1 reference: read `tests/unit/terrain/v1Heights.json` and for every point except the `notice` centre (4, 8) `abs(heightAt - h) <= 0.05` on `createHeightField({ radius: 180, flatAreas: zoneFlatAreas(ZONES), paths: zonePaths(ZONES) })` where `ZONES` is a literal copy of the 14 v1 zone `x`, `z`, `r` values INSIDE the test file (so later changes of `zones.js` never break this frozen test); plateau: the circle `{ x: 10, z: -20, r: 12, y: 5 }` without paths gives `abs(h - 5) < 0.02` at its centre, the rect `{ kind: "rect", x: 0, z: 0, hx: 10, hz: 6, blend: 6, y: 1 }` gives `abs(h - 1) < 0.02` at 20 points inside and exactly the unflattened value at a point 6 m outside; island edge: at 72 angles with `d = radius` the height is -3.0 (1e-9) and for `d` in 0.95, 1.0 and 1.05 times the radius every height is below `waterLevel - 1`; range: on a 2 m grid over [-210, 210]^2 every value is in [-12, 40]; `slopeAt` is below 0.01 at the centre of a rect flat area and equals a hand-computed central difference at one point; `isWater` is true at `d = radius` and false at the origin. splat.test.js: sums to 1 and never negative over a 50 by 50 grid of `(h from -3 to 5, slope from 0 to 1.2)` for `pathMask` 0, 0.5 and 1; `sand >= 0.99` at `h = waterLevel + 0.3` (slope 0.1, pathMask 0); `rock >= 0.99` at slope 1.0 (h 3, pathMask 0); `dirt >= 0.99` at pathMask 1 (h 3, slope 0.1); `grass >= 0.99` at h 3, slope 0.1, pathMask 0; `pathMask` is 1 on the polyline, 0 beyond `dirtHalfWidth + falloff` and monotone between; continuity on the REAL v1 field built as above: 2000 seeded points inside 0.9 of the radius, for each of the four axis directions 0.5 m away no weight changes by 0.5 or more.

- `buildTerrainMesh` details. Geometry: `PlaneGeometry(size, size, segments, segments)` rotated to the ground; each vertex `y = heightField.heightAt(x, z)`; vertex attribute `splat` (vec4 Float32) from `splatWeights({ h, slope: heightField.slopeAt(x, z), pathMask: pathMask ? pathMask(x, z) : 0 })`; normals by central differences of `heightAt` with a step of one cell; `stats.triangles` = index count / 3 = `2 * segments * segments`. Material: `MeshStandardMaterial({ roughness: 0.95, metalness: 0 })` named `terrain`, `defines: { SPLAT_LAYERS: 4 }` plus `USE_ROCK_NORMAL: 1` only when `tier === "high"`, and an `onBeforeCompile(shader)` that injects (vertex) `attribute vec4 splat; varying vec4 vSplat; varying vec3 vWPos;` and after `#include <begin_vertex>` the lines `vSplat = splat; vWPos = (modelMatrix * vec4(transformed, 1.0)).xyz;`; (fragment) uniforms `uMap0` to `uMap3` (sampler2D), `uHas` (vec4, 1 when that layer has a loaded map), `uFlat0` to `uFlat3` (vec3, the `flat` colours), `uTile` (vec4 = 4, 3, 3, 5) and, under `USE_ROCK_NORMAL`, `uRockNormal`; the `#include <map_fragment>` chunk is replaced by: for each layer `p = vWPos.xz`, colour = `uHas.i > 0.5 ? mix(texture2D(uMapI, p / tile).rgb, texture2D(uMapI, rot(p, 0.6) / (tile * 4.3)).rgb, 0.35) : uFlatI` (the second sample at another scale and rotation hides tiling), then `diffuseColor.rgb *= sum(colour_i * w_i) / max(dot(vSplat, vec4(1.0)), 0.0001)`. Under `USE_ROCK_NORMAL` the rock normal map (tile 5 m, sampled at `vWPos.xz / 5.0`) perturbs the normal with weight `vSplat.w` and `normalScale` 1.2, using a derivative based tangent frame: copy the `perturbNormal2Arb` function from the installed three chunk `normalmap_pars_fragment` (read it in node_modules first, the signature depends on the three version) into the injected header. `mesh.onBeforeRender` copies, every frame, `holder.map || WHITE_1PX` into `uMapI.value`, `uHas`, and `holder.normalMap || FLAT_NORMAL_1PX` into `uRockNormal.value` from the `textures` holders (late loads and tier swaps of plan 013 therefore need no rebind); every sampler uniform starts as a 1x1 DataTexture (white, and (128,128,255) for the normal) so no sampler is ever unbound. With `textures: null` (Node, unit tests) all layers use their flat colour. Samplers in the final fragment shader: 4 colour plus 1 rock normal, at most 5.
