# Plan 037: Houses, shop rows, cafe and market from archetype manifests, baked per block

Epic E3. Estimated turns: 60.

## Goal

Fill the plots of the town plan with believable buildings. Six archetypes (house-a: single-storey tiled-roof house with a pillared front veranda; house-b: two-storey flat-roof house with a water tank; shop-row: a row of three shops with roll-down shutters and signboards; cafe: an enterable tea and snack cafe; market: an open pillared market hall with stalls; hut: a small thatched fisherman hut) are parameterised by archetype files, built by the kit, tinted in pastel colours, and baked into merged meshes per 80 m block so about 40 plots cost few draw calls. Only the cafe is enterable; every other building has closed decorative doors and curtain-filled windows.

Fixed conventions (every later plan relies on them). (1) Plot data comes from plan 032: `{ id, type, x, z, w, d, rot, facing }` with `x, z` the plot centre, `w` along the plot local x, `d` along the plot local z, `rot` radians used as Three.js `rotation.y`, so the building front looks along `(sin rot, cos rot)` (ARCH 10.8) and `facing` is the derived compass letter N|E|S|W. ONE door rule: every archetype has its front door on the manifest wall `S` (local +z), the placement is `{ x: plot.x, z: plot.z, rot: plot.rot, y: floorY }`, so the door faces `(sin rot, cos rot)`; the door faces the plot `facing` exactly when `rot` is a multiple of PI/2 and within PI/4 of it otherwise. (2) Instance id: `instantiate` gives the building id `town-<index>` where `index` is the position of the plot in `town.plots` (so ids never depend on `plot.id`); the kit then prefixes colliders, lights and door ids with it as in ARCH 10.8 (`town-12:wall:3`, `door:town-12:main`, `town-12:lamp-1`); `validateManifest` already accepts any non-zone id (the cottage fixture uses `cottage`). (3) Block ids: the island is cut into a grid of 80 m cells, `ix = floor((x + town.radius) / 80)`, `iz = floor((z + town.radius) / 80)`, block id `town-<ix>-<iz>` (this is also the streamer area id; plan 040 tests that every plot lies in exactly one block), `bounds = { x0, x1, z0, z1 }` of the cell, `centre` the cell midpoint. (4) Extras (portico, steps, balcony, awning, water tank, parapet, outside staircase, rolling shutter, curtain, bench, pots) are never manifest classes (ARCH 10.8 exterior kit): they are decorators in `src/world/town/decorate.js` keyed by archetype and added through `instance.addDetail` (plan 025), never discovered by glob. (5) Reuse, do not duplicate: baking is plan 029 `src/world/town/bakeStatic.js` (this plan does NOT create `src/world/kit/bake.js` nor a second bake function); read that file first and call it exactly as it is exported.
