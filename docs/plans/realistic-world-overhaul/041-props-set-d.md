# Plan 041: Prop set D: office, technology and broadcast studio (44 types)

Epic E4. Estimated turns: 60.

## Goal

Fourth furniture set for the office tower, the broadcast station, the gatehouse control room and the garage and studio buildings: 44 new types (office 16, tech 12, media 16). Same quality bar, metadata conventions (origin at the footprint centre, front toward +z, `size[1]` = top of the geometry, wall and ceiling props never solid, `lightSockets`, `textSlots`, kept parts) and materials rules as plans 019, 022 and 023: read `docs/world-conventions.md` ("Prop metadata") and the existing set files first. Every type below is registered with exactly the `size`, `solid`, `mount`, seats and `topY` of its table row; the tests assert the tables.

Conventions fixed here (written into `docs/world-conventions.md` by this plan; plans 047 and 061 rely on them). (1) Screens: a screen is a `textSlots` entry with `type: "screen"` (`{ id, type: "screen", x, y, z, w, h }`, same rectangle meaning as a text slot, facing +z); entries without `type` are text slots. ONE array shape: there is no `userData.screen`. A building shows content on a screen by drawing on that rectangle or by lighting it; the screen face is the dark material `screenDark` by default. (2) Blink: `meta.animated = { kind: "blink", period: 1.2, on: 0.3 }` and the blinking parts are the meshes whose name starts with `keep-blink` (step 1). (3) ON AIR: `setOnAir(object, bool)` of `src/world/props/sets/media.js` (step 4). (4) Emissive colours and the extra flat materials come from `src/world/props/extraMaterials.js` only; no set file creates a material inline.
