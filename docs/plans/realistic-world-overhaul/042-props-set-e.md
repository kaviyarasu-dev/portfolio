# Plan 042: Prop set E: library, museum, school, post office, security and transport (49 types)

Epic E4. Estimated turns: 60.

## Goal

Fifth furniture set for the library, the town hall, the academy, the post office, the gatehouse and the ferry terminal: 49 new types (library 10, museum 10, school 8, post 9, security 6, transport 6). Same quality bar, metadata conventions (origin at the footprint centre, front toward +z, `size[1]` = top of the geometry, wall and ceiling props never solid, `lightSockets`, `textSlots`, kept parts) and materials rules as plans 019, 022, 023 and 041: read `docs/world-conventions.md` ("Prop metadata") and the existing set files first. Every type below is registered with exactly the `size`, `solid`, `mount`, seats and `topY` of its table row; the tests assert the tables.

Conventions used here. (1) Screens are `textSlots` entries with `type: "screen"` (plan 041; there is no `userData.screen`). (2) Emissive colours and extra flat materials come from `src/world/props/extraMaterials.js` (`getEmissive("red"|"green"|"amber")`, `greenScreen`, `screenDark`, `brass`, `paper`, `leather`, `foliage`, `rubber`, `plastic` (always with a `tint`), `wicker`, `cork`); no set file creates a material inline. Orange life jackets are `fabric` with `tint` #e8631a. (3) `animated` kinds used: `spin` (plan 022: the spinning part is the child group named `blades`) and `swing`, which this plan defines (step 1 and ARCHITECTURE 10.8): `animated: { kind: "swing", axis: "z", min, max, speed, node: "keep-boom" }`. (4) No real person is depicted (`bust-abstract` is a geometric head).
